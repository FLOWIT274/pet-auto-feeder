# ADR 0002: 猫狗检测模型选型 — YOLOv8n 宠物特化 优于 SSD-320

**状态**:已采纳（2026-08-07）

## 决策
SG2002 设备端猫狗检测采用 **re_pet_person（YOLOv8n, letterbox 384×640, cat/dog/person 3 类, INT8 cvimodel）** 作为唯一方案,废弃 catdog_detect_320 SSD。

## 背景 / 权衡

在 COCO val2017 官方含猫狗图集（349 图 / 420 实例,含 202 cat + 218 dog）上做了同一图集、同一 IoU 评估链路的全量对比:

| 指标 | catdog_320 (SSD) | re_pet_person (YOLOv8n) |
|---|---|---|
| 图片级全目标命中 | 25/349 (7.2%) | 275/349 (78.8%) |
| cat @IoU0.5 | 6.9% | 86.6% |
| dog @IoU0.5 | 8.7% | 71.6% |
| 平均置信度（真阳） | 0.37-0.49 | 0.77 |

证据可信度:设备 TPU 真机推理输出,解码/坐标还原/GT 匹配同链,配 5 张图目视复核通过（成功 3 + 漏检 1 + 错分 1）。

## 失败模式（pet 模型已知边界）

- 贴图边缘的小目标易漏检（示例 miss_000000049810:左边缘猫漏）
- cat/dog 视觉相近图有低置信错分（示例 wrong_000000077396:cat→dog conf≈0.50）
- GT 含极端小目标（13×8px）的图必然漏

## 结论

性能差距（10 倍以上）且置信度可信,无继续保留 SSD 的必要。产品线后续检测一律走 YOLOv8n 宠物特化链路。
