# ADR 0003: 推理技术栈定案 — v8n 检测器路线，否决 ImageNet 零样本分类器

**状态**: 已采纳（2026-08-13）

## 决策

SG2002 猫狗识别推理栈 = **yolov8n_det_pet_person 检测链路**（VDEC→TPU→DFL→NMS→轨迹匹配），
**否决分类器补充方案**（Xception / MobileNetV2 ImageNet 预训练权重 + 猫狗类 logits 零样本聚合）。

## 背景 / 权衡

### 分类器方案动机与实测
v8n 存在猫狗互换误检（vdec_tpu30 缓解后 2.9% 跳变），曾设想用强分类器裁决。
零样本方案（无需微调）：Keras 官方权重，猫类 [281,283,284,285] + 狗类 83 个品种 logits 聚合比大小。
**fp32 精度实测 95%（200 张 = 19/20，logits 与 softmax 聚合一致）**——方法本身有效。

### 否决原因一：设备端量化灾难（INT8 链路全断）
| 尝试 | 结果 |
|---|---|
| Xception INT8（缩略图校准） | 狗类 logits 系统性损坏（聚合恒约 -50），猫全对狗全错 |
| Xception INT8（1200 张高清校准） | 同样失效 |
| 校准顺序修正（猫狗交错 600 张） | 同样失效 |
| 输出层混合精度（qtable MatMul→BF16） | 输出不变（bf16 量化后仍坏） |
| 去 Softmax 只出 logits | 校准可行但 INT8 中间层已毁 |
| 全 BF16 | 52MB 超 ION 内存上限，设备 OOM |
| asymmetric INT8 | **cv181x 不支持**（AvgPoolLowering `!asymmetric` 断言） |

根因链：INT8 输出层量化把小 logits 抹零（Keras 狗聚合 0.60 来自 83 类每类 ~0.007；
输出层 scale ~0.4，0.007 级直接量化为 0/负）→ softmax 输出被压扁（max 0.065）→
**设备端 CVI_NN 拿到的只有量化的 softmax 概率，logits 不可用**。

### 否决原因二：结构性缺陷（与量化无关，fp32 也死）
1. **互斥二分类无法猫狗共判**——sum(cat) vs sum(dog) 比大小，同框猫狗只能选一个
2. **无"无目标"门控**——87/1000 类聚合天然占优，空场景/人物/景物会被强行判猫或狗，误报不可控

### 检测器路线的验证（同日）
BV1UAV5e5Eu9 真实视频实测（yolov8n + v30 轨迹，6649 帧全量）：
检出 3653 帧（54.9%），dog 3227 / person 540 / cat 42，置信度 0.32-0.95（avg 0.71），
全程无频繁类别跳变（22 次切换中 19 次是 person↔dog 的真实人狗互动，仅 6 次单帧孤立抖动）。
每框一类 + conf 阈值 + 无目标输出 = 天然满足共判与门控。

## 结论

检测器是猫狗识别唯一正解。产品线推理栈按 ADR 0002 + 本 ADR 定案；
后续改进只走"换更强检测模型"（yolov8s 384x640 推算 25fps）或后处理优化，不再引入分类器。
